# Linear Algebra Course Map Index

## Purpose

This file defines the official course structure for the Linear Algebra Bridge project.

The project is designed for first-year Chinese university students encountering linear algebra in an English-medium classroom for the first time.

Its primary purpose is not to teach the full course from the beginning. It helps students:

- connect core English terminology with standard Chinese mathematical concepts;
- recognize the language commonly used in lectures, textbooks, and exercises;
- become familiar with English pronunciation and classroom expressions;
- preview the conceptual structure of each topic before class.

The course map follows the teaching scope in the official syllabus, *Linear Algebra and Its Applications (Blended)* (《线性代数及其应用（混合式）》课程教学大纲).

The primary English-language textbook listed in the syllabus is:

David C. Lay, *Linear Algebra and Its Applications*, 5th Edition, Pearson, 2014.

The syllabus also references the trial lecture notes *Linear Algebra and Its Applications (New Engineering)* (《线性代数及其应用（新工科）》), prepared by the Linear Algebra Course Group of the School of Mathematics at Tianjin University.

Only the main instructional sections within the official course scope are included in this index. Teaching objectives, assessment arrangements, review sessions, and detailed teaching-hour allocations are not treated as knowledge-page sections.

This file is the master navigation reference for the entire project.

## Course Scope

This project currently covers seven chapters:

1. Prerequisites and an Introduction to Systems of Linear Equations
2. Matrices
3. Determinants
4. Vector Spaces of n-Tuples
5. Vector Spaces
6. Eigenvalues, Eigenvectors, and Linear Transformations
7. Euclidean Spaces and Quadratic Forms

All chapters and sections are currently planned unless their status is updated after review.

## Generation Rules

When generating a new knowledge page:

- Always follow this course structure and the official syllabus scope.
- Treat English-Chinese terminology bridging as the primary learning objective.
- Prioritize written term recognition, pronunciation, classroom sentences, and notation reading before mathematical depth.
- Help students recognize terminology, pronunciation, definitions, and classroom usage; do not turn a page into a full replacement for the course.
- Use one simple mathematical example or short step animation where it helps connect English wording to a visible action.
- Avoid extended calculation and advanced cases in the standard pre-class flow.
- Use the English section title in navigation and retain the official Chinese title as the bilingual reference.
- Only create pages within Chapters 1-7 unless the course scope is explicitly revised.
- Do not create sections that are not listed here unless they are first approved and added to this index.
- Do not silently move a topic from one chapter or section to another.
- Follow `Knowledge_Page_Template_V1.md` and `Bilingual_Mathematics_Content_Guidelines_V1.md`.
- Follow `Hero_Card_Design_Guidelines_V1.md` and `Mathematical_Visualization_Guidelines_V1.md` when visual content is used.
- Run `Knowledge_Page_Reviewer_V1.md` and `Responsive_Visual_QA_Addendum_V1.md` before marking a page complete.
- Existing approved pages must remain unchanged unless revision is explicitly requested.
- Update status labels only after the corresponding review stage has been completed.
- This file is the highest-level navigation reference for the Linear Algebra Bridge project.

## Source Note

Course coverage and Chinese section titles were derived from the official syllabus file `线性代数大纲.pdf`, especially the teaching-content and teaching-hour-allocation sections.

The syllabus contains a few inconsistent internal numbering labels. This index normalizes them into a continuous Chapter.Section format from 1.1 through 7.5 while preserving the stated content order and scope.
