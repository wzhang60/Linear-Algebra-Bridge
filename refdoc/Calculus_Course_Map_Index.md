\# Calculus Course Map Index



\## Purpose



This file defines the official course structure for the Calculus Bridge project.



The website follows the structure of the official textbook:



James Stewart, \*Calculus (7th Edition)\*



The website follows the structure of the official textbook within the current course coverage.



The current development scope includes Chapters 1–9.



Only the main instructional sections are included.



The following are intentionally excluded:



\- Preface

\- Diagnostic Tests

\- Chapter Reviews

\- Problems Plus

\- Applied Projects

\- Laboratory Projects

\- Writing Projects

\- Appendices



This file is the master navigation reference for the entire project.



\# Course Scope



This project currently covers:



James Stewart Calculus (7th Edition)



Chapters 1–9 only.





Chapters 10–11 are outside the current development scope.





Future expansion may be considered separately.

\- Do not create sections that are not listed here.
