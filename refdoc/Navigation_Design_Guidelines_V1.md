\# Navigation Design Guidelines V1





\## Purpose



This document defines the navigation system for Calculus Bridge.



The navigation should help students understand:



\- Course structure

\- Textbook hierarchy

\- Learning progress

\- Available knowledge pages





The navigation follows the textbook structure.







\# Navigation Hierarchy





The navigation contains three levels:





\## Level 1: Chapter





Example:



Chapter 3

Differentiation Rules





Purpose:



Represent major textbook chapters.





Requirements:



\- Highest visual priority.

\- Always clickable.

\- Active chapter should be highlighted.







\---





\## Level 2: Textbook Section





Example:



3.2 The Product and Quotient Rules





Purpose:



Represent textbook sections.





Requirements:



\- Always clickable.

\- Should not appear disabled.

\- Maintain clear hierarchy with topics.

\- Use medium visual emphasis.







\---





\## Level 3: Knowledge Topic





Example:



Product Rule





Purpose:



Represent individual learning pages.





Requirements:



\- Always clickable.

\- Strongest emphasis among section children.

\- Active topic should have highlight state.







\# Interaction Rules





All navigation levels must be interactive.





Avoid:



\- Visible but non-clickable items.

\- Disabled-looking textbook sections.

\- Inconsistent click behavior between levels.







\# Active State





When a user selects an item:





Active item:



\- Darker text color.

\- Background highlight.

\- Clear visual feedback.





Inactive items:



\- Lighter color.

\- Remain readable.







\# Layout Rules





The hierarchy should be visually clear:





Chapter



↓



Section



↓



Topic





Do not make lower-level items appear more important than higher-level structure.





\# Generation Rules





When adding new chapters or topics:



\- Follow this navigation system.

\- Do not create independent navigation styles.

\- Preserve consistent interaction patterns across all chapters.
